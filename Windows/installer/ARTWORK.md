# Installer artwork

The light and dark artwork is the same artwork shipped in Sukut's Windows
installer. It uses the approved Sukut identity, a warm neutral palette and the
Arabic slogan: إنترنت بدون موسيقى.

The app title retains its familiar damma: سُكوت. Original artwork was generated
and revised using image generation; the master PNGs are retained unchanged.
The setup overlays accessible native text and uses local IBM Plex Sans Arabic
and Handjet font resources. Font licenses are retained alongside the assets.

`SukutHandjet.ttf` is a static instance of the Handjet variable font (wght600,
ELGR1, ELSH2), with the internal family renamed Sukut Handjet. It is registered
privately for setup and released on exit; no system font is installed.
