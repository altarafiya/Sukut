# GitHub artwork

The hero and platform strip extend the existing Sukut vector identity and use
the original launcher artwork. They are documentation graphics, not screenshots.
The hero's vector source and deterministic renderer are included. To regenerate,
provide @resvg/resvg-js and run `node tools/render-github-artwork.cjs`.
Readex Pro uses its bundled SIL Open Font License. The app artwork is unchanged.
