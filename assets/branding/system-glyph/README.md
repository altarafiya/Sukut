# Sukut system glyph (س)

The original س used before 0.5.0 for small system icons: the Windows and Linux tray, the Android Quick Settings tile and the Android notification. 0.5.1 keeps it there, while the app icon is the hand (`../sukut-app-icon.png`, cut from `../hand-icon-design-2026-11-13/`).

`tools/export-branding.py` copies these files into the app resources unchanged. Taken from the public repository's last pre-0.5.0 commit.
