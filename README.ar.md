## أوضاع الصوت

| الوضع | ما تسمعه |
| --- | --- |
| إيقاف | الصوت الأصلي. |
| مرشّح الموسيقى | الكلام والأصوات الأخرى، مع كتم الموسيقى. |
| المحسّن | الموسيقى مكتومة، مع إمكانية ضبط صوت الخلفية. |
| الصارم | الكلام، مع كتم الموسيقى والخلفية. |

تختلف النتائج عند تداخل الأصوات. وقد يزيل الوضع الصارم المؤثرات الصوتية أيضًا.

اختر العربية أو الإنجليزية، والمظهر الفاتح أو الداكن، وأيقونة التطبيق. يتيح ويندوز ولينكس أيضًا اختيار التطبيق المصدر ومخرج الصوت.

## الإعداد

- **ويندوز:** ثبّت من متجر مايكروسوفت، أو استخرج ملف ZIP وافتح `Sukut.exe`. ثبّت [VB-CABLE](https://vb-audio.com/Cable/)، ثم اتبع دليل الترحيب. نسخة ZIP غير موقّعة.
- **أندرويد:** ثبّت ملف APK حتى يتوفر التطبيق على جوجل بلاي. اتبع دليل التفعيل عبر التصحيح اللاسلكي (أندرويد 11 أو أحدث)، أو عبر USB من سُكوت على ويندوز أو لينكس (أندرويد 10 أو أحدث).
- **أوبونتو:** شغّل الأمر التالي، ثم افتح سُكوت واتبع خطوات إذن الصوت التي يعرضها. للحزم الأخرى، راجع [دليل لينكس](Linux/README.md#packages).
